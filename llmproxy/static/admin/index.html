Automation & maintenance

Free-models updater & cost probe

Sweep every is the cadence: how often the free-models updater runs at all (0 = every check, 7 = weekly). Last run is cached in update_state.json.

Cost-probe at most every only throttles the cost probe within a sweep, so it can never make it run more often than the sweep (0 = every sweep). Last run is cached in cost_probe_state.json. Set it slightly below the sweep cadence, or an equal value can slip a cycle and effectively double. The :free-discovery probe has no frequency of its own and runs on every sweep.

Probe timeout is the read timeout shared by both probes.

Propose providers.json changes as a PR

Token needs contents:write + pull_requests:write. Blank = keep the current token; falls back to the GITHUB_TOKEN / GH_TOKEN env var. Works even on a read-only image (mirrors the computed files to your config dir and opens the PR from there).
